Usage Instructions

  • Place all icon files in the root /public directory
  • Update the HTML head section with the provided meta tags
  • Create a manifest.webmanifest file
  • For production, convert SVG to PNG formats at specified sizes
  • Use SVG for modern browsers, ICO for compatibility
