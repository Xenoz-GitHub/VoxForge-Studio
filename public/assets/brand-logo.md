# VoxForge Studio - Brand Logo System

## Logo Concept
A sophisticated, modern logo that combines audio/speech technology with creative studio elements. The design should reflect:
- **Vox (Voice)**: Speech, audio waves, sound
- **Forge**: Creation, craftsmanship, technology
- **Studio**: Creativity, precision, workspace

## Color Palette
- Primary: Orange (#F97316) - Creative energy, warmth
- Secondary: Slate (#64748B) - Professional, tech-focused
- Accent: Emerald (#10B981) - Quality, clarity
- Background: White/Slate-950 - Clean, professional

## Logo Variants

### 1. Main Logo (Wordmark + Symbol)
**VoxForge Studio** with integrated audio wave + microphone/soundwave icon

### 2. Icon Only
Abstract representation of voice waveform merging with studio tools

### 3. Simplified Mark
For favicon, mobile app icons, etc.

## Design Elements
- Clean, geometric shapes
- Smooth curves representing sound waves
- Studio/tool references (mic elements, precision lines)
- Modern sans-serif typography
- Responsive scaling for all use cases

## Usage Guidelines
- Minimum size: 24px for icon, 48px for wordmark
- Clear space: 1x logo height around all sides
- Color variations for light/dark themes
- Background contrast requirements
